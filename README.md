# 🧠 DocuMind AI: Enterprise RAG System

**DocuMind AI** is an intelligent, context-aware Retrieval-Augmented Generation (RAG) application. It allows users to upload unstructured documents (PDFs and Text files) and securely interact with their data using natural language, powered by the lightning-fast **Llama 3.1** model via the Groq API.

Built with a focus on seamless user experience, it features a sleek chat interface driven by **Streamlit**.

---

## 🚀 Key Features

*   **Intelligent RAG Architecture**: Extracts document context and injects it into the LLM's prompt for highly accurate, hallucination-free answers.
*   **Multi-Format Support**: Seamlessly parses `.pdf` and `.txt` files.
*   **Conversational Memory**: Maintains chat history in the session state for contextual follow-up questions.
*   **Ultra-Fast Inference**: Utilizes `llama-3.1-8b-instant` via Groq for real-time document analysis.
*   **Modern UI**: Clean, responsive, and intuitive chat interface built entirely in pure Python.

---

## 🛠️ Technology Stack

*   **Frontend / UI**: Streamlit
*   **AI / LLM**: Llama 3.1 (Groq API)
*   **Document Parsing**: PyPDF2
*   **Language**: Python 3
